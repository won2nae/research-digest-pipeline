- **작성일**: 2026-09-20 (평가 대상 실험 실행일: 2026-09-14)
- **목적**: 리서치 자동화 파이프라인의 요약 생성 단계에 어떤 언어모델을 쓸지 결정하기 위한 정량 비교
- **배경**: Claude API 사용량 한도 부담 때문에, 로컬에서 무료로 돌릴 수 있는 오픈소스 모델로 대체 가능한지 검증할 필요가 있었음

## 1. 실험 설계

### 1.1 테스트 데이터
- 2026-09-14 네이버 파이낸셜 '매크로(경제)' 카테고리 리포트 11건 원문 (`data/2026-09-14/naver_macro.json`)

- 주의: Qwen3-0.6B / Qwen2.5-7B-Instruct / Qwen3-8B는 최초 수집분(10건) 기준으로 실행됐고, 이후 Llama-3.1-8B / Qwen3-14B / Qwen3-32B는 재수집분(11건) 기준으로 실행됨 — 원문 건수가 1건 차이나지만 핵심 이슈 구성은 동일함

### 1.3 평가 방법: LLM-as-a-judge (루브릭 기반)
사람이 직접 각 요약을 읽고 채점하는 대신, **Claude를 채점자로 사용**해 5개 기준에 대해 1~5점씩 채점하게 함 (`llm_judge.py`). 채점자에게는 원문 리포트 전체와 평가 대상 요약을 같이 주고, 정해진 루브릭에 따라 점수+근거를 요구했다.

| 기준 | 정의 |
|---|---|
| 정확성 | 원문의 수치·사실과 일치하는가. 환각(없는 내용을 지어냄) 여부 |
| 분석적 종합 | 단순 나열이 아니라 여러 리포트의 근거를 하나의 경제적 인과관계/메커니즘으로 엮어냈는가 |
| 교차비교 | 증권사 간 시각 차이를 포착하고, 왜 다른지 설명했는가 |
| 구조·가독성 | 소제목 구성, 문단 흐름, 마크다운 구조의 읽기 편의성 |
| 완결성 | 원문의 핵심 이슈를 빠짐없이 다뤘는가 |

만점 25점 (기준당 5점 × 5개).

**루브릭 설계는 자체적으로(자의적으로) 정한 것**이며, 별도의 공인된 벤치마크나 외부 검증을 거치지 않았음 — 이 파이프라인의 실제 사용 목적(증권사 리포트 종합 브리핑)에 맞춰 임의로 정의한 평가축임을 밝혀둔다.

## 3. 모델별 상세 코멘트 (채점자 원문 요약)

**Qwen3-14B (17/25, 1위)** — 수치 인용이 정확하고 마크다운 구조가 가장 깔끔함. 유진투자증권 vs SK증권의 물가 해석 차이는 포착했으나, 가장 핵심적인 대립축인 "9월 FOMC 인상 vs 동결"(유안타·유진 vs iM증권)은 정면으로 대비시키지 못함. 채권시장 함의, ECB/BOJ 관련 내용 일부 누락.

**Qwen3-32B (15/25)** — 정확성·가독성은 14B와 동급이나, 교차비교 점수가 더 낮음(2점) — iM증권과 유안타증권의 핵심 시각 차이를 아예 포착하지 못함. **모델 크기가 크다고 항상 더 잘 쓰는 것은 아님을 보여주는 사례** (샘플링 변동성 가능성 있음, 1회성 비교의 한계).

**Qwen3-8B (15/25)** — iM증권 섹션에서 같은 원문 내용을 대조 구도인 것처럼 이중 서술하는 오류 발견. 대체로 준수하나 인과 메커니즘 통합이 약함.

**Qwen2.5-7B-Instruct (13/25)** — 수치 정확도는 양호하나 분석적 종합·교차비교·완결성 모두 낮음. 구세대 모델의 한계로 해석됨.

**Llama-3.1-8B-Instruct (10/25)** — **환각 발견**: 원문에 없는 내용을 지어내거나(섹션 5 "달러가 유로보다 유가·금리와 약한 관계"), 인용 출처를 잘못 귀속(Supercore CPI 수치를 SK증권이 아닌 한화투자증권 리포트에서 인용해놓고 SK증권으로 표기). 한국어 금융 도메인에서는 Qwen 계열보다 신뢰도가 낮음.

**Qwen3-0.6B (7/25)** — 실사용 불가 수준. 여러 증권사 요약에 동일 문장을 그대로 복사해 반복 삽입, 헤더 중복("## ##"), 출처 혼동 다수.

## 4. 결론 및 후속 조치

1. **Qwen3-14B를 프로덕션 요약 모델로 채택** — 6개 모델 중 최고점(17/25)이며, GPU 1장에서 합리적 속도(오늘 기준 데이터 처리 시 총 6분대)로 동작.
2. **공통 약점 발견**: 1위인 Qwen3-14B조차 "분석적 종합"(3/5), "교차비교"(3/5) 점수가 상대적으로 낮았음. 즉 대부분의 모델이 "증권사가 이렇게 말했다"를 나열하는 데 그치고, 왜 그런 결론에 이르는지 경제적 인과관계로 엮어내지 못하는 공통 실패 패턴을 보임.
3. **이 발견을 바탕으로 프롬프트를 개정함** (2026-09-16, `summarize.py`) — "OO증권은 ~라고 밝혔다" 식 나열을 명시적으로 금지하고, "무슨 일이 일어나는가 → 왜 그런가(경제적 메커니즘) → 그래서 어떤 의미인가"의 3단 구조로 서술하도록 지시문을 강화. 개정 후 실제 산출물(9/15 채권 카테고리)에서 인과 서술이 눈에 띄게 개선됨을 정성적으로 확인함 (`output/2026-09-15/bond.md`).
4. **향후 과제**: 이번 루브릭 평가는 개정 전 프롬프트로 실행됐으므로, 개정된 프롬프트 기준으로 재평가가 필요함. 또한 "분석적 종합"·"교차비교" 약점이 프롬프트만으로 해결 안 될 경우, Claude 출력을 정답(gold label)으로 삼은 distillation 파인튜닝(LoRA)을 다음 단계로 고려.
